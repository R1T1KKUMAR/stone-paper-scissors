# Stone Paper Scissors

Rock-Paper-Scissors vs random computer, first to 5. Zero-build static site.

## Run
Open `index.html` directly, or:
```bash
npx serve .
```

## Structure
- `index.html` (`button#rock/paper/scissors`) → `script.js` (121 lines) + `style.css`

## Notes
- Accessible: `aria-live/dialog`, focus + `Esc` reset, responsive, `prefers-reduced-motion`.
